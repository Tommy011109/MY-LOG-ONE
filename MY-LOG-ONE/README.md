# MY-LOG ONE v1.0.0 公開候補版
VS Code の Live Server で index.html を開く。GitHub Pages では7ファイルを同じディレクトリに配置する。
OCRはTesseract.jsのCDNと学習データを使用するためネット接続が必要な場合がある。画像はブラウザ内で処理する。睡眠の翻訳は辞書方式、未登録英文は原文を維持。筋トレの感想は原文を維持。AI実験ページは公開版に含まない。
シフトの補完時刻は推定なので元画像と照合すること。別の月の画像、iPhone、公開環境は未検証。設定と筋トレ下書きはブラウザのローカルストレージに保存される。
更新時は sw.js のキャッシュ名も更新する。キャッシュ削除は本アプリのキャッシュのみ対象。
